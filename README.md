# Sistema de Cadastro em Python

Este projeto é um **sistema de cadastro desenvolvido em Python**, criado como parte do meu processo de aprendizado em desenvolvimento back-end com Python, com foco em boas práticas, organização de código e persistência de dados.

O sistema permite realizar operações completas de CRUD e gerar relatórios automatizados em Excel.

---

## Funcionalidades

- ✅ Cadastrar pessoas
- ✅ Listar cadastros
- ✅ Editar cadastros existentes
- ✅ Remover cadastros
- ✅ Persistência de dados em arquivo JSON
- ✅ Geração automática de relatório em Excel (.xlsx)
- ✅ Validação de dados inseridos pelo usuário:
  - Nome (apenas letras)
  - Idade (entre 1 e 120)
  - Email (validação básica)

---

## Conceitos Aplicados

- Modularização de código
- Manipulação de arquivos JSON
- Estrutura de repetição e validação
- Organização em múltiplos arquivos
- Geração automatizada de relatórios com `openpyxl`
- Uso de `if __name__ == "__main__"`
- Separação de responsabilidades (SRP)

---

## Tecnologias Utilizadas

- Python 3
- Biblioteca openpyxl
- Git
- GitHub
- Visual Studio Code

---

## Como Executar o Projeto

1. Clone o repositório
2. Execute `main.py`
3. Para gerar relatório, execute `gerar_relatorio.py`
